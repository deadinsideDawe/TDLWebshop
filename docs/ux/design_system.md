# Design rendszer / vizuális nyelv

## UI megközelítés
- Angular standalone komponensek
- saját CSS alapú stílusrendszer
- kártyás layout + modál + badge + toast minták

## Színpaletta
- Primary: `#119DFF`
- Secondary: `#84CC16`
- Accent: `#38BDF8`
- Success: `#22C55E`
- Warning: `#F97316`
- Error: `#EF4444`
- Surface: `#161D27`
- Background: `#0B0F14`
- Text: `#F8FAFC`
- Text muted: `#94A3B8`

## Tipográfia
- Címsor: erős, display jellegű (Oswald/Bebas stílus)
- Törzsszöveg: Inter jellegű sans-serif
- Tipikus méretek:
  - hero cím: 48-72 px
  - szekciócím: 28-40 px
  - normál szöveg: 14-18 px

## Elrendezés
- Alap spacing: 8 px rendszer
- Tartalomszélesség: kb. 1200-1320 px
- Reszponzív grid: mobil, tablet, desktop töréspontokkal

## Ikonok
- Egyedi SVG elemek
- Kategória ikonok
- Státusz badge-ek (raktáron / kevés / nincs)

## Sötét mód
- támogatott
- elsődleges vizuális irány a sötét téma
- világos módban külön kontraszt finomhangolás

## Breakpointok
- mobil: `0-767 px`
- tablet: `768-1023 px`
- desktop: `1024+ px`

## Tervezesi megjegyzes
A sotet alaptema a TDLWebshop ipari, technikai arculatat erositi, a vilagos tema pedig tisztabb, uzletiesebb alternativat ad. A kek es piros accent szinek a logo vilagahoz igazodnak, igy a felulet dark es light modban is ugyanazt a brandet tartja.
