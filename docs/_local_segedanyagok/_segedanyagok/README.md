# Segedanyagok

Ez a mappa nem a szakdolgozat fo beadando szovege, hanem a munka kozbeni segedanyagok helye.

Ide kerulhetnek:

- renderelt DOCX/PDF munkapeldanyok,
- korabbi szakdolgozati vazlatok es atnezesi jegyzetek,
- kepernyokep-listak es sajat ellenorzesi jegyzetek,
- termekimport-sablonok,
- AI-atirasi es vedesi felkeszulesi jegyzetek,
- olyan anyagok, amelyek segitik a beadast, de nem onallo fejezetkent kerulnek a dolgozatba.

Beadaskor a dolgozat fo szoveget, a vegleges README-t, a tesztelesi/biztonsagi/adatmodell dokumentumokat es a kodot kell eloterbe tenni. Ez a mappa arra valo, hogy a munkafajlok ne keveredjenek a vegleges bizonyito anyagokkal.

Almappak:

- `renderelt_munkapeldanyok/`: PDF vagy renderelt ellenorzesi kimenetek.
- `render_javitott_docx/`: a javitott Word-alap PDF exportja vizualis ellenorzeshez.
- `vazlatok_es_atnezesek/`: korabbi DOCX vazlatok es sajat javitasi jegyzetek.
