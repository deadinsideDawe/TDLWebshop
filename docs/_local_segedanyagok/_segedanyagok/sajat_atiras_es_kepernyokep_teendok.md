# Sajat atiras es kepernyokep teendok

Ez a fajl neked szol, nem feltetlenul beadando melleklet. Arra valo, hogy a veglegesitesnel gyorsan lasd, melyik anyagot kell meg sajat nyelvezetre athuzni, es melyik kepernyokep hianyzik.

## Sajat nyelvezetre atirando fontos anyagok

Ezeket a fajlokat erdemes a vegleges leadashoz kulonosen atnezni, mert ezekben erzodik meg legjobban, ha tul "asszisztens-szagu" marad a fogalmazas:

## Amit ne hagyj benne a vegleges dolgozatban

- `ATIRVA`, `TODO`, `ide majd`, `majd kesobb` jellegu nyomok.
- Emoji vagy nyilas magyarazat szakdolgozati szovegben.
- Tul altalanos mondatok bizonyitek nelkul.
- Olyan allitas, amit nem tudsz kepernyokeppel, koddal vagy teszttel alatamasztani.

## Kepernyokepek minimum listaja

- Kezdolap dark mode, kategoria lenyiloval.
- Kezdolap AI asszisztenssel.
- Termeklista szuresekkel.
- Termekadatlap.
- Kosar tobb termekkel.
- Checkout hibas email/telefonszam validacioval.
- Checkout sikeres rendeles utan.
- Profil es rendeleskovetes.
- Kivansaglista.
- Admin attekintes.
- Admin termekkezeles es CSV import.
- Admin keszletfigyeles.
- Helyszini vasarlas mentett vasarloval.
- General PDF szamla/bizonylat.
- Admin felhasznalo es jogosultsag kezeles.
- GitHub Actions zold CI.

## Utolso sajat ellenorzes

Minden nagyobb fejezet vegen tedd fel magadnak ezt a harom kerdest:

1. El tudom magyarazni, miert igy keszult?
2. Van hozza kod, kepernyokep vagy teszt bizonyitek?
3. Ugy hangzik, ahogy en is elmondanam vedesen?

Ha a harmadik valasz nem, akkor azt a bekezdest sajat szavakkal meg kell huzni.
